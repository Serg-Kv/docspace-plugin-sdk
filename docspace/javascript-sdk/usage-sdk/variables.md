# Variables

Exported constants: the default frame configuration, the iframe name prefix, the CSP validation endpoint and the error messages the SDK shows.

## Overview

The following constants are available:

| Constant | Description |
| --- | --- |
| [`connectErrorText`](https://api.onlyoffice.com/docspace-plugin-sdk/docspace/javascript-sdk/usage-sdk/variables/connectErrorText.md) | The error message displayed when the message bus fails to connect with the embedded frame. |
| [`CSPApiUrl`](https://api.onlyoffice.com/docspace-plugin-sdk/docspace/javascript-sdk/usage-sdk/variables/CSPApiUrl.md) | The API endpoint for managing Content Security Policy (CSP) settings. |
| [`cspErrorText`](https://api.onlyoffice.com/docspace-plugin-sdk/docspace/javascript-sdk/usage-sdk/variables/cspErrorText.md) | The error message displayed when the current domain is not included in the CSP settings. |
| [`defaultConfig`](https://api.onlyoffice.com/docspace-plugin-sdk/docspace/javascript-sdk/usage-sdk/variables/defaultConfig.md) | The default configuration object for initializing and embedding a DocSpace frame. |
| [`FRAME_NAME`](https://api.onlyoffice.com/docspace-plugin-sdk/docspace/javascript-sdk/usage-sdk/variables/FRAME_NAME.md) | The default name for the DocSpace iframe element. |
