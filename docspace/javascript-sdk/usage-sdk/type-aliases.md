# Type Aliases

Configuration, event, filter and data shapes exchanged with the embedded frame. Most integrations only need `TFrameConfig` and `TFrameEvents`; the remaining types describe what the instance methods accept and return.

## Overview

The following types are available:

| Type | Description |
| --- | --- |
| [`TBannerDisplaying`](https://api.onlyoffice.com/docspace-plugin-sdk/docspace/javascript-sdk/usage-sdk/type-aliases/TBannerDisplaying.md) | The template literal type for the display options of the header banner. |
| [`TEditorCustomization`](https://api.onlyoffice.com/docspace-plugin-sdk/docspace/javascript-sdk/usage-sdk/type-aliases/TEditorCustomization.md) | The editor customization configuration. |
| [`TEditorType`](https://api.onlyoffice.com/docspace-plugin-sdk/docspace/javascript-sdk/usage-sdk/type-aliases/TEditorType.md) | The template literal type based on the `EditorType` enum. |
| [`TEventReturnData`](https://api.onlyoffice.com/docspace-plugin-sdk/docspace/javascript-sdk/usage-sdk/type-aliases/TEventReturnData.md) | The event return data structure. |
| [`TFilterSortBy`](https://api.onlyoffice.com/docspace-plugin-sdk/docspace/javascript-sdk/usage-sdk/type-aliases/TFilterSortBy.md) | The template literal type representing the filter sort options. |
| [`TFilterSortOrder`](https://api.onlyoffice.com/docspace-plugin-sdk/docspace/javascript-sdk/usage-sdk/type-aliases/TFilterSortOrder.md) | The template literal type representing the filter sort order. |
| [`TFrameConfig`](https://api.onlyoffice.com/docspace-plugin-sdk/docspace/javascript-sdk/usage-sdk/type-aliases/TFrameConfig.md) | The frame configuration. |
| [`TFrameEvents`](https://api.onlyoffice.com/docspace-plugin-sdk/docspace/javascript-sdk/usage-sdk/type-aliases/TFrameEvents.md) | The frame event handlers. |
| [`TFrameFilter`](https://api.onlyoffice.com/docspace-plugin-sdk/docspace/javascript-sdk/usage-sdk/type-aliases/TFrameFilter.md) | The frame filter criteria. |
| [`TFrameMode`](https://api.onlyoffice.com/docspace-plugin-sdk/docspace/javascript-sdk/usage-sdk/type-aliases/TFrameMode.md) | The template literal type representing the frame mode based on `SDKMode`. |
| [`TManagerViewMode`](https://api.onlyoffice.com/docspace-plugin-sdk/docspace/javascript-sdk/usage-sdk/type-aliases/TManagerViewMode.md) | The template literal type representing the manager view mode. |
| [`TMessageData`](https://api.onlyoffice.com/docspace-plugin-sdk/docspace/javascript-sdk/usage-sdk/type-aliases/TMessageData.md) | The message data structure. |
| [`TMessageTypes`](https://api.onlyoffice.com/docspace-plugin-sdk/docspace/javascript-sdk/usage-sdk/type-aliases/TMessageTypes.md) | The template literal type for message types. |
| [`TSelectorType`](https://api.onlyoffice.com/docspace-plugin-sdk/docspace/javascript-sdk/usage-sdk/type-aliases/TSelectorType.md) | The template literal type for the selector filters. |
| [`TTask`](https://api.onlyoffice.com/docspace-plugin-sdk/docspace/javascript-sdk/usage-sdk/type-aliases/TTask.md) | The task object structure. |
| [`TTheme`](https://api.onlyoffice.com/docspace-plugin-sdk/docspace/javascript-sdk/usage-sdk/type-aliases/TTheme.md) | The template literal type representing the theme options. |
