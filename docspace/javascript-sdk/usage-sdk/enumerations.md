# Enumerations

Typed constants for frame modes, themes, editor layouts and sort options. Use them in place of the raw string values they stand for.

## Overview

The following enumerations are available:

| Enum | Description |
| --- | --- |
| [`EditorType`](https://api.onlyoffice.com/docspace-plugin-sdk/docspace/javascript-sdk/usage-sdk/enumerations/EditorType.md) | The available types of editor interface. |
| [`FilterSortBy`](https://api.onlyoffice.com/docspace-plugin-sdk/docspace/javascript-sdk/usage-sdk/enumerations/FilterSortBy.md) | The criteria for filtering and sorting items. |
| [`FilterSortOrder`](https://api.onlyoffice.com/docspace-plugin-sdk/docspace/javascript-sdk/usage-sdk/enumerations/FilterSortOrder.md) | The item sorting order. |
| [`HeaderBannerDisplaying`](https://api.onlyoffice.com/docspace-plugin-sdk/docspace/javascript-sdk/usage-sdk/enumerations/HeaderBannerDisplaying.md) | The display settings of the header banner. |
| [`InstanceMethods`](https://api.onlyoffice.com/docspace-plugin-sdk/docspace/javascript-sdk/usage-sdk/enumerations/InstanceMethods.md) | Available instance methods in the SDK for file management, user information, and settings. |
| [`ManagerViewMode`](https://api.onlyoffice.com/docspace-plugin-sdk/docspace/javascript-sdk/usage-sdk/enumerations/ManagerViewMode.md) | The view modes available in the manager. |
| [`MessageTypes`](https://api.onlyoffice.com/docspace-plugin-sdk/docspace/javascript-sdk/usage-sdk/enumerations/MessageTypes.md) | The types of messages exchanged between SDK components and the host application. |
| [`SDKMode`](https://api.onlyoffice.com/docspace-plugin-sdk/docspace/javascript-sdk/usage-sdk/enumerations/SDKMode.md) | The available modes for initializing the SDK. |
| [`SelectorFilterType`](https://api.onlyoffice.com/docspace-plugin-sdk/docspace/javascript-sdk/usage-sdk/enumerations/SelectorFilterType.md) | The filter type used in the selector views. |
| [`Theme`](https://api.onlyoffice.com/docspace-plugin-sdk/docspace/javascript-sdk/usage-sdk/enumerations/Theme.md) | The available application themes. |
