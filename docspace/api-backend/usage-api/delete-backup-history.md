# Delete the backup history

`DELETE /api/2.0/backup/deletebackuphistory`

Deletes the backup history from the current portal.

Operation ID: `deleteBackupHistory`

## Authorization

One of:

- `asc_auth_key` (apiKey) — `asc_auth_key` in cookie
- `Bearer` (http bearer)
- `ApiKeyBearer` (apiKey) — `ApiKeyBearer` in header
- `Basic` (http basic)
- `OAuth2` (oauth2)
- `OpenId` (openIdConnect)

## Parameters

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Dump` | query | boolean | No | Specifies if a dump will be created or not. Example: `true`. |
