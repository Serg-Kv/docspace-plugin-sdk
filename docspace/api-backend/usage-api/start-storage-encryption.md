# Start the storage encryption process

`POST /api/2.0/settings/encryption/start`

Starts the storage encryption process.

Operation ID: `startStorageEncryption`

## Authorization

One of:

- `asc_auth_key` (apiKey) — `asc_auth_key` in cookie
- `Bearer` (http bearer)
- `ApiKeyBearer` (apiKey) — `ApiKeyBearer` in header
- `Basic` (http basic)
- `OAuth2` (oauth2)
- `OpenId` (openIdConnect)

## Request body

Content type: `application/json`

| Property | Type | Required | Description |
| --- | --- | --- | --- |
| `notifyUsers` | boolean | No | Specifies whether the users receive notifications about the storage encryption operations. Example: `true`. |

Example:

```json
{
  "notifyUsers": true
}
```
