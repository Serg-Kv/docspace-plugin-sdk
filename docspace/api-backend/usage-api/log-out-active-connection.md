# Log out from the connection

`PUT /api/2.0/security/activeconnections/logout/{loginEventId}`

Logs out from the connection with the ID specified in the request.

Operation ID: `logOutActiveConnection`

## Authorization

One of:

- `asc_auth_key` (apiKey) — `asc_auth_key` in cookie
- `Bearer` (http bearer)
- `ApiKeyBearer` (apiKey) — `ApiKeyBearer` in header
- `Basic` (http basic)
- `OAuth2` (oauth2)
- `OpenId` (openIdConnect)

## Parameters

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `loginEventId` | path | integer (int32) | Yes | The ID of the specific login event. Example: `9846`. |
