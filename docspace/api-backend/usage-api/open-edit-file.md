# Open a file configuration

`GET /api/2.0/files/file/{fileId}/openedit`

Returns the initialization configuration of a file to open it in the editor.

Operation ID: `openEditFile`

## Parameters

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fileId` | path | integer (int32) | Yes | The file ID to open. Example: `9846`. |
| `version` | query | integer (int32) | No | The file version to open. Example: `1234`. |
| `view` | query | boolean | No | Specifies if the document will be opened for viewing only or not. Example: `true`. |
| `editorType` | query | string | No | The editor type to open the file. One of: `Desktop`, `Mobile`, `Embedded`. Example: `Desktop`. |
| `edit` | query | boolean | No | Specifies if the document is opened in the editing mode or not. Example: `true`. |
| `fill` | query | boolean | No | Specifies if the document is opened in the form-filling mode or not. Example: `true`. |
