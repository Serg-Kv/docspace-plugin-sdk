# Get account entries

`GET /api/2.0/accounts/room/{id}/search`

Returns the account entries with their sharing settings in a room with the ID specified in request.

Operation ID: `getAccountsEntriesWithRoomsShared`

## Authorization

One of:

- `asc_auth_key` (apiKey) — `asc_auth_key` in cookie
- `Bearer` (http bearer)
- `ApiKeyBearer` (apiKey) — `ApiKeyBearer` in header
- `Basic` (http basic)
- `OAuth2` (oauth2)
- `OpenId` (openIdConnect)

## Parameters

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | integer (int32) | Yes | The user ID. Example: `9846`. |
| `employeeStatus` | query | string | No | The user status. One of: `Active`, `Terminated`, `Pending`, `Default`, `All`. Example: `Active`. |
| `activationStatus` | query | string | No | The user activation status. One of: `NotActivated`, `Activated`, `Pending`, `AutoGenerated`. Example: `NotActivated`. |
| `excludeShared` | query | boolean | No | Specifies whether to exclude the account sharing settings from the response. Example: `true`. |
| `includeShared` | query | boolean | No | Specifies whether to include the account sharing settings in the response. Example: `true`. |
| `invitedByMe` | query | boolean | No | Specifies whether the user is invited by the current user or not. Example: `true`. |
| `inviterId` | query | string (uuid) | No | The inviter ID. Example: `75a5f745-f697-4418-b38d-0fe0d277e258`. |
| `area` | query | string | No | The area of the account entries. One of: `All`, `People`, `Guests`. Example: `All`. |
| `employeeTypes` | query | string[] | No | The list of the user types. One of: `All`, `RoomAdmin`, `Guest`, `DocSpaceAdmin`, `User`. |
| `count` | query | integer (int32) | No | The number of items to retrieve in a request. Example: `1234`. |
| `startIndex` | query | integer (int32) | No | The starting index for the query results. Example: `1234`. |
| `filterSeparator` | query | string | No | Specifies the separator used in filter expressions. Example: `some text`. |
| `filterValue` | query | string | No | The text filter applied to the accounts search query. Example: `some text`. |
