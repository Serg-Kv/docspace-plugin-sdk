# Move group members

`PUT /api/2.0/group/{fromId}/members/{toId}`

Moves all the members from the selected group to another one specified in the request.

Operation ID: `moveMembersTo`

## Authorization

One of:

- `asc_auth_key` (apiKey) — `asc_auth_key` in cookie
- `Bearer` (http bearer)
- `ApiKeyBearer` (apiKey) — `ApiKeyBearer` in header
- `Basic` (http basic)
- `OAuth2` (oauth2)
- `OpenId` (openIdConnect)

## Parameters

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fromId` | path | string (uuid) | Yes | The group ID to move from. Example: `75a5f745-f697-4418-b38d-0fe0d277e258`. |
| `toId` | path | string (uuid) | Yes | The group ID to move to. Example: `75a5f745-f697-4418-b38d-0fe0d277e258`. |
