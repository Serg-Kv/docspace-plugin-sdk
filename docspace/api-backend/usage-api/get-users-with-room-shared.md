# Get users with room sharing settings

`GET /api/2.0/people/room/{id}`

Returns the users with the sharing settings in a room with the ID specified in request.

Operation ID: `getUsersWithRoomShared`

## Authorization

One of:

- `asc_auth_key` (apiKey) — `asc_auth_key` in cookie
- `Bearer` (http bearer)
- `ApiKeyBearer` (apiKey) — `ApiKeyBearer` in header
- `Basic` (http basic)
- `OAuth2` (oauth2)
- `OpenId` (openIdConnect)

| `employeeStatus` | query | string | No | The user status. One of: `Active`, `Terminated`, `Pending`, `Default`, `All`. Example: `Active`. |
