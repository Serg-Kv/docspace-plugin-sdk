# Put money on deposit

`POST /api/2.0/portal/payment/deposit`

Returns the result of putting money on deposit.

Operation ID: `topUpDeposit`

## Authorization

One of:

- `asc_auth_key` (apiKey) — `asc_auth_key` in cookie
- `Bearer` (http bearer)
- `ApiKeyBearer` (apiKey) — `ApiKeyBearer` in header
- `Basic` (http basic)
- `OAuth2` (oauth2)
- `OpenId` (openIdConnect)

## Request body

Content type: `application/json`

| Property | Type | Required | Description |
| --- | --- | --- | --- |
| `amount` | integer (int32) | No | The amount of money for the operation. Example: `1234`. |
| `currency` | string, nullable | No | The three-character ISO 4217 currency symbol. Example: `some text`. |

Example:

```json
{
  "amount": 1234,
  "currency": "some text"
}
```
