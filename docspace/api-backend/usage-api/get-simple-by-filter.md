# Search users by extended filter

`GET /api/2.0/people/simple/filter`

Returns a list of users matching the parameters specified in the request.

Operation ID: `getSimpleByFilter`

## Authorization

One of:

- `asc_auth_key` (apiKey) — `asc_auth_key` in cookie
- `Bearer` (http bearer)
- `ApiKeyBearer` (apiKey) — `ApiKeyBearer` in header
- `Basic` (http basic)
- `OAuth2` (oauth2)
- `OpenId` (openIdConnect)

## Parameters

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `employeeStatus` | query | string | No | The user status. One of: `Active`, `Terminated`, `Pending`, `Default`, `All`. Example: `Active`. |
| `groupId` | query | string (uuid) | No | The group ID. Example: `75a5f745-f697-4418-b38d-0fe0d277e258`. |
| `activationStatus` | query | string | No | The user activation status. One of: `NotActivated`, `Activated`, `Pending`, `AutoGenerated`. Example: `NotActivated`. |
| `employeeType` | query | string | No | The user type. One of: `All`, `RoomAdmin`, `Guest`, `DocSpaceAdmin`, `User`. Example: `All`. |
| `employeeTypes` | query | string[] | No | The list of user types. One of: `All`, `RoomAdmin`, `Guest`, `DocSpaceAdmin`, `User`. |
| `isAdministrator` | query | boolean | No | Specifies if the user is an administrator or not. Example: `true`. |
| `payments` | query | string | No | The user payment status. One of: `Paid`, `Free`. Example: `Paid`. |
| `accountLoginType` | query | string | No | The account login type. One of: `SSO`, `LDAP`, `Standart`. Example: `SSO`. |
| `quotaFilter` | query | string | No | The quota filter (All - 0, Default - 1, Custom - 2). One of: `All`, `Default`, `Custom`. Example: `All`. |
| `withoutGroup` | query | boolean | No | Specifies whether the user should be a member of a group or not. Example: `true`. |
| `excludeGroup` | query | boolean | No | Specifies whether the user should be a member of the group with the specified ID. Example: `true`. |
| `invitedByMe` | query | boolean | No | Specifies whether the user is invited by the current user or not. Example: `true`. |
| `inviterId` | query | string (uuid) | No | The inviter ID. Example: `75a5f745-f697-4418-b38d-0fe0d277e258`. |
| `area` | query | string | No | The filter area. One of: `All`, `People`, `Guests`. Example: `All`. |
| `count` | query | integer (int32) | No | The maximum number of items to be retrieved in the response. Example: `1234`. |
| `startIndex` | query | integer (int32) | No | The zero-based index of the first item to be retrieved in a filtered result set. Example: `1234`. |
| `sortBy` | query | string | No | Specifies the property or field name by which the results should be sorted. Example: `some text`. |
| `sortOrder` | query | string | No | The order in which the results are sorted. One of: `Ascending`, `Descending`. Example: `Ascending`. |
| `filterSeparator` | query | string | No | Represents the separator used to split filter criteria in query parameters. Example: `some text`. |
| `filterValue` | query | string | No | The search text used to filter results based on user input. Example: `some text`. |
