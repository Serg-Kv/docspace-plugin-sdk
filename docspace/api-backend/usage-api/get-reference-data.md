# Get reference data

`POST /api/2.0/files/file/referencedata`

Returns the reference data to uniquely identify a file in its system and check the availability of insering data into the destination spreadsheet by the external link.

Operation ID: `getReferenceData`

## Authorization

One of:

- `asc_auth_key` (apiKey) — `asc_auth_key` in cookie
- `Bearer` (http bearer)
- `ApiKeyBearer` (apiKey) — `ApiKeyBearer` in header
- `Basic` (http basic)
- `OAuth2` (oauth2)
- `OpenId` (openIdConnect)

## Request body

Content type: `application/json`

| Property | Type | Required | Description |
| --- | --- | --- | --- |
| `fileKey` | string, nullable | Yes | The unique document identifier used by the service to get a link to the file. Example: `some text`. |
| `instanceId` | string, nullable | Yes | The unique system identifier. Example: `9846`. |
| `sourceFileId` | integer (int32) | No | The source file ID. Example: `1234`. |
| `path` | string, nullable | No | The file name or relative path for the formula editor. Example: `some text`. |
| `link` | string, nullable | No | The file link. Example: `some text`. |

Example:

```json
{
  "fileKey": "some text",
  "instanceId": "9846",
  "sourceFileId": 1234,
  "path": "some text",
  "link": "some text"
}
```
