# Overview

ONLYOFFICE custom AI tools are editor extensions that combine the plugin framework with an AI provider integration to deliver intelligent, context-aware features directly inside the editors.

If you prefer to start coding right away, go directly to the [quick start guide](https://api.onlyoffice.com/docspace-plugin-sdk/docs/ai/get-started/quick-start.md).

## What you can build

Build next-generation document workflows powered by AI.

**Perfect for**:

- Writing assistance ([Rewrite text](https://api.onlyoffice.com/docspace-plugin-sdk/docs/ai/samples/document-editor/rewrite-text.md) - AI-powered text rewriting)
- Smart styling ([Change text style](https://api.onlyoffice.com/docspace-plugin-sdk/docs/ai/samples/document-editor/change-text-style.md) - AI-powered text styling)
- Automatic shape generation ([Add shape to slide](https://api.onlyoffice.com/docspace-plugin-sdk/docs/ai/samples/presentation-editor/add-shape-to-slide.md) - AI-powered presentation design)
- Data insights ([Explain formula](https://api.onlyoffice.com/docspace-plugin-sdk/docs/ai/samples/spreadsheet-editor/explain-formula.md) - AI-powered formula explanations)

**Development profile**:

- **Skill**: Advanced | **Tech**: Plugin API + AI provider integration
- **Requirements**: API keys for OpenAI, DeepSeek, or any OpenAI-compatible provider

[Browse all AI tool examples](https://api.onlyoffice.com/samples/?doctype=ai&text=ai+tools)
