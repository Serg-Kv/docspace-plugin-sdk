# GetAllComments

Returns all the comments from the document.

## Syntax

```javascript
expression.GetAllComments();
```

`expression` - A variable that represents an [Api](https://api.onlyoffice.com/docspace-plugin-sdk/docs/plugins/interacting-with-editors/pdf-api.md) class.

## Parameters

This method doesn't have any parameters.

## Returns

[comment](https://api.onlyoffice.com/docspace-plugin-sdk/docs/plugins/interacting-with-editors/pdf-api/Enumeration/comment.md)[]
