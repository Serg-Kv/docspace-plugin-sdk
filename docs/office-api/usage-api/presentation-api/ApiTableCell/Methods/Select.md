# Select

Selects the current table cell in the presentation.

## Syntax

```javascript
expression.Select();
```

`expression` - A variable that represents an [ApiTableCell](https://api.onlyoffice.com/docspace-plugin-sdk/docs/office-api/usage-api/presentation-api/ApiTableCell.md) class.

## Parameters

This method doesn't have any parameters.

## Returns

This method doesn't return any data.
