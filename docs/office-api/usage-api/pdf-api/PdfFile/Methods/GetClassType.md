# GetClassType

Returns a type of the PdfFile class.

## Syntax

```javascript
expression.GetClassType();
```

`expression` - A variable that represents an [PdfFile](https://api.onlyoffice.com/docspace-plugin-sdk/docs/office-api/usage-api/pdf-api/PdfFile.md) class.

## Parameters

This method doesn't have any parameters.

## Returns

"pdfFile"
