# GetClassType

Returns a type of the ApiGroup class.

## Syntax

```javascript
expression.GetClassType();
```

`expression` - A variable that represents an [ApiGroup](https://api.onlyoffice.com/docspace-plugin-sdk/docs/office-api/usage-api/pdf-api/ApiGroup.md) class.

## Parameters

This method doesn't have any parameters.

## Returns

"group"
