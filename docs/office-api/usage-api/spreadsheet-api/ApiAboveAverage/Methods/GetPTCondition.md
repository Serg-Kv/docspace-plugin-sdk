# GetPTCondition

Returns the pivot table condition object.

## Syntax

```javascript
expression.GetPTCondition();
```

`expression` - A variable that represents an [ApiAboveAverage](https://api.onlyoffice.com/docspace-plugin-sdk/docs/office-api/usage-api/spreadsheet-api/ApiAboveAverage.md) class.

## Parameters

This method doesn't have any parameters.

## Returns

PTCondition \| null
