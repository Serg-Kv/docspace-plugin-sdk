# CreateParagraph

Creates a new empty paragraph.

## Syntax

```javascript
expression.CreateParagraph();
```

`expression` - A variable that represents an [ApiDocument](https://api.onlyoffice.com/docspace-plugin-sdk/docs/office-api/usage-api/document-api/ApiDocument.md) class.

## Parameters

This method doesn't have any parameters.

## Returns

[ApiParagraph](https://api.onlyoffice.com/docspace-plugin-sdk/docs/office-api/usage-api/document-api/ApiParagraph.md)
